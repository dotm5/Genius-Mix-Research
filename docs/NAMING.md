# Genius Mix 名称与本地化

本文给出 Genius Mix 在设备列表中的名称构成、SilverDB 本地化资源格式与命名建议。

## 1 名称构成

真机观测：一个跨流派的 Genius Mix 在中文界面显示为 `<名称> 及其他`，英文为 `<名称> & others`，日文为 `<名称> など`。名称前缀取自 `container.name`，后缀由固件按当前语言拼接。

| 语言 | 分隔符 | 后缀 |
|---|---|---|
| 英语 | `, ` | ` & others` |
| 简体中文 | `，` | ` 及其他` |
| 繁体中文 | `、` | `和其他項目。` |
| 日语 | `, ` | `など` |

两个后缀 id 在 `rsrc` 中分别出现 29 / 30 次，属于在用产品资源。

后缀 id 表内可读到 `id = 0x0DAD0D07 → " & others"`；该 id 的 4 字节表示在全部镜像中只命中 id 表本身，代码、字面量池与布局描述符的引用数为 0。标题拼装函数的静态引用为 0 命中，名称构成以真机观测为准。

## 2 SilverDB 资源格式

固件按当前语言加载 `Resources/UI/SilverDB.<语言代码>.LE.bin`：

| 偏移 | 内容 |
|---:|---|
| +0x00 | u32 版本，取值 3 |
| +0x04 | u32 字符串区偏移 |
| +0x08 | u32 chunk 数（=3） |
| +0x0C | 3 × 16B chunk 头：`mTDL` / `rtS` / `tyLV` |
| +0x3C | id 表：N × 12B `{u32 id; u32 相对偏移; u32 长度}` |
| +header[1] | 字符串区 |

id 表按 id 升序排列，1,121 项；表内偏移相对字符串区起始。英文内建表位于固件本体，各语言包位于 `rsrc` 分区。

## 3 前缀的显示路径

- `container.name` 是设备 SQLite 中的原始文本。
- 语言切换只加载 SilverDB 资源，`Library.itdb` 保持不变。
- iTunes 侧的名称来自服务端 `GetGeniusMixItems` 响应中的原始名称（通常为英文流派名），写入设备时保持原样。

写进 `container.name` 的字符串原样显示，与设备语言无关。

## 4 命名建议

| 方案 | 做法 | 效果 |
|---|---|---|
| 推荐 | 语言中立或英文流派名，如 `Dance` / `Electronic` / `Pop` | 任意语言下与后缀正常组合 |
| 可用 | 纯识别码，如 `C1` … `C8` | 语言无关，适合变体测试 |
| 非首选 | 单一语言的自然名称（例如中文流派名） | 切换到其它语言后，前缀与后缀混排 |

## 5 相关字段

| 对象 | 说明 |
|---|---|
| `container.name` | 名称前缀；`name IS NOT NULL` 是容器被枚举的前提 |
| `container.name_order` | 列表排序 |
| `Dynamic.itdb.container_ui` | 容器显示状态；缺少该行时容器不被枚举 |
